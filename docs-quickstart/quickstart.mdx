AllowMe turns good habits — reading, chores, learning — into real savings your
kids can see and grow. **You set the rules. Your kids earn. You approve.**

<Note>
  **You're always in control.** Parents decide what kids can do. Kids earn and
  settle within those rails. Money can only ever go to a destination you've
  authorized — nothing can be sent somewhere you didn't approve, by anyone.
</Note>

## See it in action

Before you set anything up, here's the whole AllowMe loop in one family's week.
Watch the money go from **earned** to **in the wallet** — only after a parent
approves.

That's AllowMe: **kids earn, parents verify, money settles on approval**, and
the difference between *earned* and *in your wallet* is always visible. No
surprises, no hidden balances.

<Steps>
  <Step title="Choose your role">
    AllowMe works a little differently depending on who you are. Pick the one
    that fits, then follow the steps inside.

    <Tabs>
      <Tab title="I'm a parent setting up for my family">
        You're the **Manager** — you create the family, invite everyone, and
        set the rules.

        <Steps>
          <Step title="Connect AllowMe">
            <Tabs>
              <Tab title="Claude">
                **Fastest path:** [Open AllowMe in Claude](https://claude.ai/customize/connectors?modal=add-custom-connector&connectorName=AllowMe&connectorUrl=https%3A%2F%2Fallowme.dev%2Fmcp) — opens the Add custom connector modal with **Name** and **URL** already filled (same behavior as **Open in Claude** on the verify page).

                **No button? Add manually:**
                1. Open **Customize → Connectors → Add custom connector**.
                2. Fill in:
                   - **Name:** `AllowMe`
                   - **Remote MCP server URL:** `https://allowme.dev/mcp`
                3. Click **Add**.
                4. Click **Connect**, then complete sign-in.
              </Tab>
              <Tab title="ChatGPT">
                [Open ChatGPT connector settings](https://chatgpt.com/#settings/Connectors) — shortcut to the Apps/Connectors settings page. It does **not** pre-fill anything; complete the steps below.

                1. Open **Settings → Apps → Advanced settings**.
                2. Enable **Developer Mode** if prompted.
                3. Click **Create** to open the **New App** modal.
                4. Fill in:
                   - **Name:** `AllowMe`
                   - **Description:** `Family allowance and savings on Base`
                   - **MCP Server URL:** `https://allowme.dev/mcp`
                   - **Authentication:** `OAuth`
                5. Check **"I understand and want to continue"** on the risk warning.
                6. Click **Create**.
                7. Complete sign-in to authorize.

                <Note>
                  AllowMe is a developer-mode app today — it isn't listed in the
                  directory yet. This dev-mode path stays useful for testing even
                  after a listing exists.
                </Note>
              </Tab>
              <Tab title="Claude Code">
                ```bash
                claude mcp add --transport http allowme https://allowme.dev/mcp
                ```
              </Tab>
              <Tab title="Codex">
                Add an HTTP MCP server pointing at AllowMe in your Codex MCP
                config:

                ```json
                {
                  "mcpServers": {
                    "allowme": { "url": "https://allowme.dev/mcp" }
                  }
                }
                ```
              </Tab>
              <Tab title="Cursor">
                Add AllowMe to `~/.cursor/mcp.json`:

                ```json
                {
                  "mcpServers": {
                    "allowme": { "url": "https://allowme.dev/mcp" }
                  }
                }
                ```
              </Tab>
            </Tabs>
          </Step>
          <Step title="Try it">
            Paste any of these to start:

            ```text
            Set up a new family called the Garcias
            Invite my daughter Maya as a learner
            Set Maya's weekly allowance to $15 with 20% going to savings
            Verify that Maya read for 30 minutes today
            ```

            When you later settle balances, **AllowMe will show you exactly what
            will happen and ask you to approve before anything moves.**
          </Step>
        </Steps>
      </Tab>

      <Tab title="I was invited by my partner">
        You're a **Co-parent** — you join a family that already exists and can
        verify achievements and check progress.

        Your partner sent you a **magic link** (from the verify page) like
        `https://allowme.dev/mcp?setup=SETUP-XXXX-XXXX`. Use that **full link** as
        your connection URL — not bare `allowme.dev/mcp`.

                **No button?** Paste your full magic link into **Remote MCP server URL**, then **Add** → **Connect** → sign in. You join the family you were invited to — you don't create a new one.

        verify page). It looks like
        `https://allowme.dev/mcp?setup=SETUP-XXXX-XXXX` — use that whole link,
        not `allowme.dev/mcp` by itself.

                <Note>
                  You're joining your family — you don't set anything up. No invite
