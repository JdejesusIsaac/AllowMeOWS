# /handoff

Manual context reset and handoff. Use when a sprint has run long and context is getting cluttered.

1. Compact `implementation/progress.md` to current state. Keep Failed Approaches verbatim and summarize everything else.
2. Verify all artifacts are under budget: `research/research.md`, `planning/plan.md`, `planning/contract.md`, `implementation/progress.md`, `evaluation/test.md`.
3. Write a brief Next Steps section in `implementation/progress.md` describing exactly where the Generator should pick up.
4. Confirm `planning/contract.md` is still current; update if scope has shifted.
5. End the chat session. Start a fresh one with the agent reading progress.md Next Steps first.
