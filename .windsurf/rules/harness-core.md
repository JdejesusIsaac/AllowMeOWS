# Harness Engineering Core

- This project follows the Harness Engineering v3 framework
- 4 artifacts persist across context resets: research.md, plan.md, progress.md, test.md
- Each artifact has a budget: research.md ≤40%, others ≤20% of context
- The Generator never evaluates its own work
- Failed approaches must be read before implementation begins
- Spike validation is required for uncertain integrations
