# /new-sprint

Begin a new Harness Engineering v3 sprint:

1. **Phase 0a - Problem Framing:** Define the problem statement, "what is" statement, solution hypothesis, and scope boundary. Write these inline before proceeding.
2. **Phase 0b - Research:** Use the `@researcher` skill. Produce `research/research.md` scoped to the problem statement.
3. **Phase 0.5 - Spike:** If `research/research.md` has `⚠️` markers, run a 30-minute timeboxed spike. Append Spike Results.
4. **Phase 1 - Planning:** Use the `@planner` skill. Produce `planning/plan.md`.
5. **Phase 1.5 - Contract Negotiation:** Planner drafts `planning/contract.md`. Evaluator (`@evaluator`, Mode A) reviews and pushes back. Iterate until aligned.
6. Confirm `planning/contract.md` with the user before proceeding to implementation.
