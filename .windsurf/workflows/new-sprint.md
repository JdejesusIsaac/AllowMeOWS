# /new-sprint

Begin a new Harness Engineering v3 sprint:

1. **Phase 0a — Problem Framing:** Define the problem statement, "what is" statement,
   solution hypothesis, and scope boundary. Write these inline.

2. **Phase 0b — Research:** Invoke the @researcher skill. 
   Produce research.md scoped to the problem statement.

3. **Phase 0.5 — Spike (if needed):** If research.md has ⚠️ markers,
   run a 30-minute timeboxed spike. Append results to research.md.

4. **Phase 1 — Planning:** Invoke the @planner skill.
   Produce plan.md + Sprint Contract with dynamic rubric weights.

5. Confirm Sprint Contract with the user before proceeding to implementation.
